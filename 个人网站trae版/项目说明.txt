一、如何运行
----------------------------------------
方式一（在线）：直接用浏览器打开上面的在线访问地址。

方式二（本地）：解压本压缩包后，双击 index.html 即可在浏览器中预览，
无需安装任何环境，所有资源均在本地。

二、文件清单
----------------------------------------
index.html      网站主文件（HTML + CSS + JavaScript 全部内嵌，单文件架构）

1.jpg ~ 11.jpg  AI 技能认证证书图片（证书墙展示）

三、项目简介
----------------------------------------
基于纯 HTML / CSS / JavaScript 开发的个人简历主页，
包含明暗双主题、Canvas 粒子背景、3D 卡片交互、滚动动画、
证书灯箱预览等功能，零外部依赖，响应式适配移动端。
